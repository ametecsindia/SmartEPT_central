Environment & workflow rules (critical — read before editing)

  • Edit LIVE trees only: C:\laragon\www\smartept (product) and C:\laragon\www\smartept-central (Central). No copy/overlay deploy bats. If a tree isn't connected, ASK to add it.
  • Git on the mount: the mount forbids delete, so before/after each commit mv .git/index.lock (and .git/HEAD.lock) into _to_delete/. tmp_obj unlink warnings are benign. Commit author SmartEPT Dev <dev@ametecsindia.com>.
  • Linting: no PHP on the device VM → stage files to the cloud and run php -l there. Node is on the device for node --check and extracting a blade's single <script>.
  • ⚠ Staging can be STALE: device_stage_files sometimes returns an old cached copy. Verify against the live file with device_bash greps. To render/screenshot a page reliably, copy the live file to a new filename, stage that, then screenshot with cloud Chromium (/opt/pw-browsers/chromium).
  • Landing: served via a route with a no-cache header now (edits show without a hard refresh). It's static public/landing.html.
  • CSS gotcha (learned the hard way): the landing has generic component classes (e.g. .feat with a ::before corner triangle). Prefix any new classes (npx-*) to avoid collisions — a feat collision caused a phantom "ribbon" on the pricing card.
  • Blade edits live-serve on refresh (Laragon). Central is Laravel 13 / PHP 8.3.
